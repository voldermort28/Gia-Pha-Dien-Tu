# Plan: Responsive UI & Sơ đồ Tư duy (Mindmap)
Created: 2026-02-27T02:04:00+07:00

## Overview
Dự án Gia Phả Điện Tử đã có một lõi dữ liệu vững chắc. Giai đoạn này tập trung vào việc áp dụng phong cách thiết kế hiện đại từ `giapha-os`, đặc biệt là tối ưu hóa UI trên thiết bị di động (Responsive Layout) và phát triển giao diện Sơ đồ Phả hệ/Sơ đồ Tư duy (Mindmap) trực quan, có khả năng Zoom/Pan mượt mà trên mọi kích thước màn hình.

## Tech Stack
- Frontend: Next.js + Tailwind CSS + Framer Motion
- UI Components: Radix UI / Shadcn (nếu có) + Lucide Icons
- Visualization: React Flow (cho Mindmap) hoặc các thư viện tương tự đang dùng trong giapha-os
